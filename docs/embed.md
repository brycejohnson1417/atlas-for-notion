# Embed

Use `/embed?key=<EMBED_SHARE_KEY>` inside a Notion embed block.

Supported query params:

- `theme=dark|light|auto`
- `status=Favorite`
- `center=40.7128,-74.0060`
- `zoom=12`
- `legend=false`

Embeds are public-read for anyone with the URL. Rotate `EMBED_SHARE_KEY` to revoke old embed URLs.
